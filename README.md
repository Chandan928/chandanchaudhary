# chandanchaudhary
🌐 Personal portfolio and content platform for Chandan Chaudhary — Senior SEO Consultant & AI Growth Strategist based in Hyderabad, India.   

  Built with Next.js 16 App Router, Tailwind CSS v4, and Sanity CMS. Features a dark-mode-first design system (Midnight & Violet), embedded    
  Sanity Studio for blog management, and a full suite of pages covering SEO, AEO, GEO, AI Automation, Local SEO, and Technical SEO services.   

  Tech Stack: Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Sanity v3 · Lucide Icons · Netlify

  Features:
  - 🎨 Custom design system — CSS custom properties, dark/light mode toggle, Sora + DM Sans typography
  - 📄 20 static pages — Home, About, 6 Service pages, FAQ, Contact, Blog, Legal
  - 🖼️ Animated logo strip — 23 real client brand logos with CSS scroll animation
  - ✍️ Sanity Studio embedded at /studio — full blog CMS with post schema
  - 🔍 SEO-ready — JSON-LD structured data, sitemap.xml, robots.txt, Open Graph metadata
  - 🍪 GDPR compliant — Cookie consent banner with localStorage persistence and preference reset
  - ♿ Accessible — skip links, ARIA labels, focus traps, keyboard navigation
  - 📱 Fully responsive — 375px → 1440px breakpoints
